# Share copy

## Short description

Chat Handoff saves the important parts of a long AI conversation so you can continue the project in a new chat without starting over.

## Post

Ever hit a chat limit halfway through a project?

Chat Handoff saves the goal, completed work, unfinished work, decisions, important code and links, stopping point, and next steps. It also writes a prompt you can paste into a new chat.

Use `/handoff` when you need to move the project to a fresh conversation.

GitHub: https://github.com/ayuush1212/chat-handoff

## One-line version

Save your AI project context before the chat ends, then continue in a new conversation with one paste-ready prompt.
